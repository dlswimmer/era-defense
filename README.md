# Era Defense

A roguelite tower defense game where your army evolves from rocks to lasers, and every run ends
in a last stand. Built by David and his kids. Plays on phones (portrait) and desktop, and you can
add it to your home screen.

**Play:** https://dlswimmer.github.io/era-defense/

```
npm install
npm run dev        # http://localhost:5173  (add ?dev for lots of gold)
npm test
npm run balance    # bots play runs and report how far they get
```

- Add a tower, enemy or era by adding one entry in `src/sim/data/`.
- Kids' ideas go in [IDEAS.md](IDEAS.md) (collect them in-game with the 💡 button).
- Plan: [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md). Progress: [docs/ROADMAP.md](docs/ROADMAP.md).
